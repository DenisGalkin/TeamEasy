## 💻 О проекте

**TeamEasy** — это веб-платформа для организации совместной работы над проектами. Система позволяет пользователям:
- Создавать собственные проекты и набирать команду
-  Искать существующие публичные проекты и подавать заявки на участие
- Управлять задачами, событиями и участниками внутри проектов
- Использовать встроенные инструменты для организации работы (календарь, таск-менеджер)

## 🎯 Цели проекта

Создать централизованную платформу для управления групповыми проектами, которая объединит процессы поиска команды и организации проекта, заменив необходимость в отдельных сервисах (Хабр, ВК, Trello, Jira) и интегрируясь с профессиональными платформами (GitHub, Discord, Telegram, Figma и т.д.), обеспечив единое рабочее пространство.

## 📝 Задачи проекта

**1. Задачи по реализации поиску команды (замена поиск на Хабр/VK/Telegram):**

-   Разработать систему профилей пользователей с указанием навыков, интересов и опыта.
-   Реализовать поиск среди проектов

**2. Задачи по организации работы**

-   Внедрить инструменты для управления проектом: создание задач, распределение ролей, календарь для планирования задач, видео-встреч и других событий.
-   Создать единое пространство проекта, где будет храниться информация, а также все важные ссылки (на GitHub, Telegram, Discord, Figma и т.п.).

**3. Общие задачи:**

-   Разработать, удобный, интуитивно понятный интерфейс
-   Обеспечить конфиденциальность и безопасность пользователей

## ⚡ Актуальность проекта

Современные групповые проекты требуют привлечения участников с разными навыками для повышения эффективности разработки. Однако, на практике, помимо пользы это приносит и свои проблемы. Например, сложность в коммуникации, поиске команды и планировании задач. Это приводит к необходимости использования множества разрозненных сервисов: форумы и соцсети для поиска команды (Хабр, VK, Telegram), специализированные платформы для управления задачами (Trello, Jira) и мессенджеры для коммуникации (Discord, Telegram, Teams). Информация разбрасывается по сервисам, что доставляет неудобство и снижает производительность команды. Мой проект призван решить эту проблему за счёт создания единой и удобной платформы, которая поможет собрать все в одном месте, а также предложит лучшую альтернативу поиску команды через соцсети.

## 🛠️ Стек технологий

### Backend
- **Python** — основной язык программирования
- **Flask** — веб-фреймворк
- **Flask-SQLAlchemy** — ORM для работы с базой данных
- **Flask-Login** — управление аутентификацией пользователей
- **Werkzeug** — безопасность и обработка файлов

### Frontend
- **HTML** — разметка страниц
- **CSS**  — стилизация
- **JavaScript** — клиентская логика и AJAX
- **Jinja** — шаблонизация на сервере

### Дополнительные инструменты
- **Calendar module** — работа с датами и календарями
- **datetime** — операции с временем
- **os** — работа с файловой системой
- **Pillow** (опционально) — обработка изображений

## 🚀 Инструкция по запуску

### Требования для запуска

1. **Python**
2.  **requirements.txt**

### Установка и запуск

1. **Клонируйте или скачайте репозиторий**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустите приложение:**
```bash
python app.py
```

4. **Откройте в браузере:**
```
http://127.0.0.1:5000
```

### Начало работы

1. **Регистрация:** Перейдите по адресу `http://127.0.0.1:5000/` и создайте аккаунт
2. **Создание проекта:** После входа нажмите "Создать проект" в боковом меню
3. **Поиск проектов:** Используйте поиск для поиска публичных проектов
4. **Работа в проекте:** Внутри проекта доступны:
   - Управление участниками
   - Календарь событий
   - Таск-менеджер
   - Настройки проекта
